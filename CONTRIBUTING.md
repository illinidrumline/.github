# Contributing

Thanks for your interest in the Illini Drumline's GitHub organization.

## What lives here

This organization hosts the drumline's public code and tooling. It is not an official channel for the University of Illinois, the Marching Illini, or the drumline itself — for auditions, performances, or general questions, see [marchingillini.com](https://www.marchingillini.com/about-us/illini-drumline-2).

## Ground rules

- **No personal data.** Do not open issues, pull requests, or discussions containing names, email addresses, phone numbers, home addresses, or scraped social-media data about members, alumni, or students.
- **Brand compliance.** Visual assets must follow the [Illinois brand guidelines](https://brand.illinois.edu): the official Block I is the only university mark, and it is never modified or recolored.
- Be respectful — see our [Code of Conduct](CODE_OF_CONDUCT.md).

## Opening an issue

Use the issue templates. Include steps to reproduce, the expected and actual behavior, and the version or commit you tested.

## Pull requests

1. Fork the repository and create a topic branch.
2. Keep changes focused; one logical change per pull request.
3. Run the repository's tests or linters before submitting.
4. Fill in the pull request template.

By contributing, you agree that your contributions are licensed under the license of the repository you are contributing to.
