# Support

This organization hosts the Illini Drumline's public code and tooling.

## Questions about the drumline

For auditions, performances, history, or general questions, use the official channels:

- [Illini Drumline on marchingillini.com](https://www.marchingillini.com/about-us/illini-drumline-2)
- Instagram [@illinidrumline](https://www.instagram.com/illinidrumline/)
- X [@illini_drumline](https://x.com/illini_drumline)

## Questions about a repository

Open an issue using the templates provided. For security issues, see [SECURITY.md](SECURITY.md). For everything else, see [CONTRIBUTING.md](CONTRIBUTING.md).
