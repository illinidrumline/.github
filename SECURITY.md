# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately. Do not open a public issue.

Use GitHub's private vulnerability reporting on the affected repository (Security → Report a vulnerability), or contact the maintainer [@pngdeity](https://github.com/pngdeity) directly on GitHub.

There is no public security email address for this organization. Please do not route reports about the wider university through this organization.

## Scope

These repositories are not part of the University of Illinois' production infrastructure. Reports concerning university systems should go to the appropriate university contact instead.

## Supported versions

Unless a repository says otherwise, only the default branch is supported.
