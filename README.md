# Illini Drumline — `.github`

This repository hosts the public organization profile and default community health files for the [`illinidrumline`](https://github.com/illinidrumline) GitHub organization.

- The profile shown at [github.com/illinidrumline](https://github.com/illinidrumline) is rendered from [`profile/README.md`](profile/README.md).
- Files at the root and in [`.github/`](.github/) are inherited as defaults by any repository in the organization that does not define its own.

Nothing here is part of the University of Illinois' production infrastructure. For auditions, performances, and general questions about the drumline, see [marchingillini.com](https://www.marchingillini.com/about-us/illini-drumline-2).
